# 할 건 해야지

서브컬처 게임의 일일·주간 퀘스트와 게임 일정을 달력에서 관리하고 완료 이력을 기록하는 Flutter 앱입니다.

## Android APK 빌드

```powershell
flutter pub get
flutter build apk --release
```

APK는 `build/app/outputs/flutter-apk/app-release.apk`에 생성됩니다.

## 데이터 백업과 복원

앱을 처음 실행하면 백업 파일을 불러올지 한 번 묻습니다. 이후에는 변경한 데이터가 앱 안에 자동 저장됩니다. 메뉴의 **백업 → 백업 데이터 내보내기**에서 게임, 퀘스트, 완료 기록, 일정을 하나의 JSON 파일로 저장하고, **백업 데이터 불러오기**에서 복원할 수 있습니다. 앱을 삭제하면 앱 내부 데이터가 지워질 수 있으므로 백업 파일은 기기 외부나 클라우드에도 보관해 주세요.
